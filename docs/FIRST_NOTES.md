There are a few notes from the first test hunt.

1. New Overall Hunt Details
   1. Hunt City, State
   2. President
   3. Master of Hounds

2. Score Options
   1. There should be an option for "Pack Scoring", where the dogs scores count down from 35 to 15 and every dog after the 15 point mark also recieves 15 points. This should be an option that can be selected at the beginning of the hunt with a description next to it.

3. Entering Scores
   1. There has been complaints about entering the colon in the cross time, and it would be preferred if they could enter it without the colon like 0600 or 1300.
   2. Currently they can only use tab to navigate the boxes on the cross entry they'd like to also use the enter button as a navigational button to jump to the next box.
   3. Instead of showing the "Last crossing of day 1", the operator would like to see the last cross that was entered by them.

4. Cross Editing
   1. Currently each score is showed individually without being group with the other scores from that cross. It would be easier for the operator to see all the scores of one crossing grouped together and then they could go to that specific crossing and edit those scores.

5. Hound Distinctions
   1. There needs to be a way to enter special awards for a dog, for instance, most hunts do a "Best Mouth" and a "Classiest Hound". This will ultimately need to be printed on a report in the end, but we need somewhere in the program to enter special awards for specific dogs.
